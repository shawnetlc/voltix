# Voltix Port Guide
## Porting Moonfin Core → Voltix Fork

This document captures everything learned during the Moonfin Core 2.4.0 → Voltix port.
Use it as the starting checklist for every future port.

## l10n / Localization Workflow

Voltix uses committed generated files in `lib/l10n/`. The `l10n.yaml` must have:

```yaml
arb-dir: lib/l10n
template-arb-file: app_en.arb
output-localization-file: app_localizations.dart
output-class: AppLocalizations
nullable-getter: false
synthetic-package: false
output-dir: lib/l10n
```

**`synthetic-package: false` + `output-dir: lib/l10n` are critical.** Without them, `flutter gen-l10n` writes to `.dart_tool/flutter_gen/` and the analyzer sees stale committed files.

### Workflow when adding new l10n keys:
1. Add keys to `lib/l10n/app_en.arb`
2. Run `flutter gen-l10n`
3. Run `flutter analyze` to confirm

### Finding missing keys:
```bash
grep -o '"[a-zA-Z]*": "[^"]*"' lib/l10n/app_en.arb | cut -d'"' -f2 > voltix_keys.txt
grep -o '"[a-zA-Z]*": "[^"]*"' /path/to/upstream/lib/l10n/app_en.arb | cut -d'"' -f2 > upstream_keys.txt
diff voltix_keys.txt upstream_keys.txt
```

## Porting Cluster Checklist

For each new upstream cluster:

1. **Identify new files** — diff the upstream `lib/` tree against Voltix
2. **Copy new files** — use Python (not `xargs`) for paths with spaces:
   ```python
   import glob, shutil, os
   for f in glob.glob('/path/to/upstream/lib/cluster/**/*.dart', recursive=True):
       dest = f.replace('/upstream/', '/voltix/')
       os.makedirs(os.path.dirname(dest), exist_ok=True)
       shutil.copy2(f, dest)
   ```
3. **Replace brand strings** in all copied files:
   ```python
   import glob
   for f in glob.glob('/path/to/voltix/lib/cluster/**/*.dart', recursive=True):
       txt = open(f).read()
       txt = txt.replace('moonfin_design', 'voltix_design')
       txt = txt.replace('package:moonfin_design', 'package:voltix_design')
       open(f, 'w').write(txt)
   ```
4. **Update method channel names** in any channel files
5. **Add l10n keys** from upstream `app_en.arb` that don't exist in Voltix
6. **Run `flutter gen-l10n`** then **`flutter analyze`**
7. **Fix any structural gaps** (missing interface methods, enum constants, etc.)

## Common Analyze Error Patterns & Fixes

### Missing interface methods
When a copied file calls a method that doesn't exist on a Voltix class:
- Check upstream to see the full method signature
- Add a no-op or delegate implementation to the Voltix class
- Common offenders: `stopTranscoding`, `homeScreenSectionsApi`, `loadBookResume`, `loadBookAuthors`

### Missing enum constants
When a copied file references `SomeEnum.newValue`:
- Find where `SomeEnum` is defined in Voltix
- Add the constant — check upstream for the right value/position

### Missing named parameters on widgets
When `book_card.dart` or similar uses a param the widget doesn't declare:
- Find the widget definition
- Add the parameter with a sensible default

### Missing l10n keys
All `undefined_getter` / `undefined_method` on `AppLocalizations` — always an ARB issue:
- Add the key to `app_en.arb`
- Run `flutter gen-l10n`

### `dependency_overrides` conflicts
If `flutter pub get` fails with a version conflict on a local package:
- Move the local package from `dependencies:` to `dependency_overrides:`

### Tizen false positives
Add to `analysis_options.yaml` exclude list:
```yaml
analyzer:
  exclude:
    - _parked_2_4/**
    - flutter-tizen*/**
```

## Firebase (Push Notifications)

Firebase is used **only for push notifications** via `lib/data/services/push_messaging_service.dart`.

### Setup steps (once per project):
1. `npm install -g firebase-tools`
2. `firebase login`
3. `dart pub global activate flutterfire_cli`
4. Add `%LOCALAPPDATA%\Pub\Cache\bin` to system PATH
5. In Firebase console: Project Settings → General → Add app (Android: `cc.voltix.streaming`, iOS: `cc.voltix.streaming`)
6. Download `google-services.json` → `android/app/`
7. Download `GoogleService-Info.plist` → `ios/Runner/`
8. `flutterfire configure` — select project, select android + ios — overwrites `lib/firebase_options.dart`

### iOS push (APNs):
- Apple Developer Portal → Keys → new key with APNs checked → download `.p8`
- Firebase console → Project Settings → Cloud Messaging → upload `.p8` + Key ID + Team ID

## Backend Security (voltixstudio)

**CRITICAL — do not skip:**
`server/localAuth.ts` line ~378 — `seedVoltixAdmin()` creates a hardcoded `voltix-admin`/`admin` account on every server start. This runs unconditionally and the server has a public Azure App Service DNS. Must be locked down before exposing to real users.

## Port Verification Checklist

Before calling a port done:

- [ ] `flutter pub get` succeeds with no version conflicts
- [ ] `flutter gen-l10n` succeeds
- [ ] `flutter analyze` reports 0 errors (info lints are fine)
- [ ] All new method channels use `voltix/` prefix
- [ ] All new l10n keys added to `app_en.arb` with brand strings corrected
- [ ] `firebase_options.dart` regenerated with real credentials
- [ ] `PORT_PROGRESS.md` updated
- [ ] No files accidentally overwritten that are intentionally different (see list above)
- [ ] Backend `seedVoltixAdmin()` security reviewed

## Feature Ownership: Voltix Original vs Ported from Moonfin

### Original Voltix Features (existed in 2.2.0 base — do not overwrite)

| Feature / File | Notes |
|---|---|
| `packages/design` (`voltix_design`) | Voltix's own design system replacing `moonfin_design` |
| `lib/ui/screens/reader/book_reader_screen.dart` | Voltix uses `webview_flutter`; upstream uses `flutter_inappwebview` — keep Voltix version |
| `packages/gamepads_linux` | Local fork; must stay in `dependency_overrides` |
| Android package `cc.voltix.streaming` | Set in `android/app/build.gradle.kts` |
| iOS bundle `cc.voltix.streaming` | Voltix's own bundle ID |
| String pref keys for passthrough codecs | e.g. `pref_passthrough_truehd` — Voltix never adopted the `PassthroughCodec` enum |
| `jellyseerrBlockNsfw` preference key | Voltix kept its own key name; upstream renamed to `seerrBlockNsfw` — do not migrate |
| Backend (`voltixstudio`) | Entirely separate repo; Voltix-only, not in Moonfin at all |
| `server/localAuth.ts` seed account | Voltix-specific; hardcoded `voltix-admin`/`admin` — security risk, must be addressed |
